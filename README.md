# Crisline's 18th Birthday Invitation 🌹

A beautiful, animated 18th birthday invitation website for **Crisline**, celebrating on **December 5, 2026**.

## ✨ Features

- 🌸 **Floating petals & sparkles** background animation
- 💫 **Mouse sparkle trail** effect
- 🌹 **18 Roses section** — 18 cards with individual messages
- 🕯️ **18 Candles section** — 18 cards with birthday wishes
- 🎁 **18 Gifts section** — 18 cards with heartfelt gifts
- 📷 **Photo gallery** — 4 slots to upload Crisline's photos (click any frame)
- ⏳ **Live countdown timer** to December 5, 2026
- 📱 **Fully mobile responsive**
- 🎨 **Soft blush, rose, and gold palette**

## 📂 Files

```
INVITATION/

├── script.js    ← Animations, countdown, photo uploads

```

## 📸 How to Add Crisline's Photos

1. Open the website in a browser
2. Scroll to the **"The Birthday Girl"** section
3. Click on any photo frame
4. Select a photo from your device
5. The photo will appear instantly!

> **For deployment**: Since photos are loaded locally, you'll need to place the actual image files in the project folder and update the `index.html` `<img>` tags with the filenames.

## 🚀 Deployment Options

### Option 1 — GitHub Pages (Free)
1. Create a free account at [github.com](https://github.com)
2. Create a new repository named `crisline-birthday`
3. Upload all files (`index.html`, `style.css`, `script.js`)
4. Go to **Settings → Pages → Source: main branch**
5. Your site will be live at `https://yourusername.github.io/crisline-birthday`

### Option 2 — Netlify (Free & Easiest)
1. Go to [netlify.com](https://netlify.com)
2. Sign up for free
3. Drag and drop the entire `INVITATION` folder onto the Netlify dashboard
4. Done! You get a live URL instantly 🎉

### Option 3 — Vercel (Free)
1. Go to [vercel.com](https://vercel.com)
2. Sign in with GitHub
3. Import your repository
4. Deploy with one click

## 🎨 Customization

To change messages in the rose/candle/gift cards, open `index.html` and edit the text inside each `.tribute-card` div.
